All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- First version of the app.
- Entries for poop, water, vomit, sleep problems and stress. All details are optional.
- Special periods that can overlap, with colored bars in the calendar.
- Calendar, log and analysis (7, 14, 30, 90 days and all).
- More than one cat.
- Export to Excel and JSON backup. Summary for the vet.
- Backup and import with a preview.
- Offline use and install on the home screen (PWA).
- Time zone handling: every entry keeps its own zone, date and time.
- Strict Content Security Policy. No network requests after load.
